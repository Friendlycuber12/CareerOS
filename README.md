# CareerOS

AI-powered internship preparation platform built with FastAPI.

## Features
- Authentication
- Dashboard
- Internship Tracker
- Resume Analyzer
- Coding Analytics
- AI Study Assistant

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
