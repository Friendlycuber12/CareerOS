# CareerOS

CareerOS is an AI-powered internship and career preparation platform built with FastAPI.

## Vision
CareerOS helps students manage internships, improve resumes, track coding progress, prepare for interviews, and build a structured roadmap toward their dream career.

## Features
- Authentication
- Dashboard
- Internship Tracker
- Resume Analyzer
- Coding Analytics
- AI Study Assistant

## Tech Stack
- FastAPI
- Python
- SQLite/PostgreSQL
- HTML/CSS/JavaScript

## Getting Started

### Installation
```bash
git clone https://github.com/Friendlycuber12/CareerOS.git
cd CareerOS
pip install -r requirements.txt
uvicorn main:app --reload
```
